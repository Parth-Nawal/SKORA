# User guide

1. Start the backend and seed the database.
2. Start the frontend.
3. Sign in using the demo credentials in the README.
4. Review the dashboard and skill library.
5. Add skills, log practice, take assessments, and attach evidence.
6. Upload a text-based PDF or DOCX resume for local text extraction.
7. Paste a job description to view detected skill coverage.

Scores are estimates based on recorded signals. Use the system as a reflective planning tool, not as a certification of professional competence.
